Nhat Tin Logistics Integration

The Nhat Tin Logistics Integration module for Odoo is designed to connect the Odoo ERP system seamlessly with Nhat Tin Logistics (NTL). This module provides features like placing orders, getting quotes, printing shipping labels, and tracking shipments directly from the Odoo interface.

Features

Booking delivery order
Booking delivery orders directly from the Odoo system.
Estimate cost delivery
Retrieve delivery quotations for orders from Nhat Tin Logistics.
Print Shipping Labels
Print shipping labels when orders are confirmed in Odoo.
Cancel Order
Cancel existing orders in Nhat Tin Logistics directly from Odoo.
Delivery Tracking via Webhook
Receive updates progress delivery of Nhat Tin Logistics through webhooks.
Dynamic APIs Configuration
Configure APIs dynamically to integrate with Nhat Tin Logistics from UI Odoo.

Getting started

  • Download Shipping Methods Base module in here

Install Nhat Tin Logistics Integration module

Nhat Tin Logistics shipping method configuration

In this section, we will proceed to set the parameters and connect to Nhat Tin Logistics Server to get the access token. This access token will help authenticate API connections with the Nhat Tin Logistics Server.

Step 1: By going to Inventory ‣ Configuration ‣ Delivery ‣ Shipping Methods

Click on a Nhat Tin Logistics record to edit your delivery method on the back end.

Click on an Integrated Configuration Tab.

Step 2: Input:

  • Username
  • Password
  • PartnerID

Tips

Click on button to check the connection status to the Nhat Tin Logistics server

Click on button to switch to a production environment or vice versa (development environment)

Step 3: Click on button

Step 4: Configure default parameters for delivery orders

  • Weight Unit: The unit of measure for your shipment. You don't need to change it because NTL rules are Kilograms
  • Service Type: List of available services provided by NTL
  • Cargo Type: Extended list of services from available services provided by NTL
  • Payment Method: Code of goods transported

Step 5: Configure a webhook to track orders called from the NTL system

Activate "Authentication Use". Then click the button to get the access token code. If you don't want to secure for your Odoo system. You can skip this step.

After generate the access token for webhook, your webhook path will look like:

Tips

At this point, contact NTL IT and send them your webhook information. They will add it to the NTL system.

Step 6: Configure routes for API.

Navigate Routes Tab, Here you can edit basic information for your restful API such as methods, headers, path, etc,

Finally, Congrats, you have successfully configured the necessary components to connect to the NTL system.

Estimate cost delivery

After creating your first customer. In this section, we will estimate the shipping costs for your sales order.

Step 1: By going to Sales ‣ Create a new sale order

Step 2: Click on button to open pop up Add a shipping method

Step 3: Choose Service Type

Step 4: Click on button to get estimated cost from NTL carrier

Step 5: Click on button to confirm add cost to the sale order

Finally, You have successfully estimated the shipping costs for your sales order

Booking delivery order

Once the cost has been estimated and confirmed by your customer. We will proceed to create a delivery order with the NTL carrier.

Step 1: By going to Inventory ‣ Delivery Orders ‣ Choose Delivery Order ‣ Additional Info Tab

Step 2: Choose information of delivery order

Step 3: Click on button .The system will validate the picking and automatically book the order

Tips

Click on button to view details of carrier reference orders.

Finally, Congrats, You have successfully booked the shipping for your sales order.

Printing Delivery Labels

Click on button to print order of NTL

Finally, Congrats, You have successfully print the delivery order.

Cancel delivery order

Click on button to cancel the delivery order.

Finally, Congrats, You have successfully cancel the delivery order.
